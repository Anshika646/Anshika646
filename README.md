- **Empirical Optimization**: Formulating objective loss functions $\mathcal{L}(\theta)$ and driving convergence via gradient descent algorithms ($\theta := \theta - \eta \nabla \mathcal{L}$).
- **Non-Linear Decision Surfaces**: Mapping feature spaces through kernel transformations, deep activations ($\mathrm{ReLU}, \sigma(z)$), and ensemble decision boundaries.
- **Probabilistic Modeling & Distributions**: Utilizing Gaussian assumptions $\mathcal{N}(\mu, \sigma^2)$, Bayes theorem $P(A|B) = \frac{P(B|A)P(A)}{P(B)}$, and hypothesis testing for significance verification.
